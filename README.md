# سایت تولد فائزه

این یک سایت استاتیک و واکنش‌گراست؛ برای نمایش آن به API یا سرور نیاز نیست.

## انتشار رایگان با GitHub Pages
1. وارد GitHub شوید و یک مخزن جدید بسازید (مثلاً `faezeh-birthday`).
2. فایل `index.html` را در ریشه مخزن بارگذاری کنید.
3. از مسیر **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.
5. پس از چند دقیقه سایت با نشانی `https://USERNAME.github.io/faezeh-birthday/` در دسترس خواهد بود.

نکته: GitHub Pages سایت را میزبانی می‌کند؛ API نیست. این پروژه برای یک صفحه تبریک تولد به API احتیاجی ندارد.
